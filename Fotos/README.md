# Pasta Fotos — envie seus arquivos aqui

Coloque nesta pasta todos os arquivos que você quer que eu use no site (logo, favicon, fotos, imagens de produtos, etc.).

Instruções rápidas para enviar arquivos pelo GitHub (web):

1. Acesse o repositório: https://github.com/TarotLuz/TarotLuz/tree/gh-pages
2. Navegue até a pasta "Fotos" (ou crie-a clicando em "Add file → Create new file" e criando um arquivo dentro dela).  
3. Para enviar arquivos, clique em "Add file → Upload files" e arraste os arquivos do seu computador para a área de upload.  
4. Certifique-se de que os nomes de arquivo não contenham espaços (use hífen ou underscore) e mantenha extensões comuns: .svg, .png, .jpg, .jpeg, .webp.
5. Antes de confirmar, verifique o caminho — os arquivos devem ficar em `Fotos/<seu-arquivo>.jpg` (por exemplo: `Fotos/logo.jpg`).
6. Em "Commit changes", escreva uma mensagem curta (ex.: "adiciona logo e favicon em Fotos") e confirme o commit direto na branch `gh-pages`.

O que eu farei depois que você enviar os arquivos

- Avisando-me aqui (responda "Pronto"), eu vou procurar os arquivos dentro da pasta `Fotos` na branch `gh-pages`, baixar e integrar no site:
  - Substituirei `assets/logo.svg` por `assets/logo.jpg` (ou manterei o SVG se você enviar SVG).
  - Atualizarei `assets/favicon.svg` se você enviar um favicon, ou converterei/ajustarei conforme necessário.
  - Atualizarei `index.html` e `shop.html` para apontarem para os novos arquivos quando necessário.
  - Publicarei as mudanças e te aviso quando o site estiver com o novo logo.

Observações

- Nomes sensíveis a maiúsculas: `Fotos/logo.jpg` é diferente de `Fotos/Logo.jpg`.
- Se preferir que eu faça o upload por você, me avise — mas preciso dos arquivos (anexo ou link de download direto).  

Quando terminar o upload, responda "Pronto" e eu começo a integração.
